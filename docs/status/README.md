# Status Documents

`docs/status/CURRENT_PROJECT_STATE.md` is the single authoritative current operational status document.

All other files in this directory are historical snapshots or narrow supporting reports unless `CURRENT_PROJECT_STATE.md` explicitly identifies them as a current supporting artifact. Historical files are preserved for auditability and may contain stale percentages, stale counts, or pre-checkpoint blocker descriptions.

Use `docs/DOCUMENTATION_INDEX.md` for the complete document map.
