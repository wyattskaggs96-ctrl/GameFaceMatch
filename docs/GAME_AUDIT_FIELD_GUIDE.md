# Game Audit Field Guide

NOT PRODUCTION DATA
NOT A VERIFIED GAME RECORD

This guide defines how Wyatt records College Football 27 appearance catalog evidence. It does not authorize invented options.

## Required Session Fields

- Audit session ID: stable local ID for the console-side audit session.
- Platform: exact console/platform being audited.
- Game version: visible game version from the shipping game.
- Patch/build identifier: patch, build, or update evidence when visible.
- Game mode: Road to Glory unless verified evidence says otherwise.
- Creation path: exact Road to Glory creation path walked from the game menu.
- Auditor: person entering evidence.
- Capture date: ISO date of screenshot capture.

## Required Record Fields

- Stable internal ID generated by the auditor.
- Category discovered from the game UI.
- Exact visible label or index from the game UI.
- Five required screenshot asset IDs.
- Capture conditions.
- Human annotation notes.
- Menu navigation instructions with evidence asset.
- First-review record.
- Second-review record from a different reviewer.
- Verification state.

## Verification State Rules

- `unverified`: draft record entered from evidence.
- `rejected`: reviewer found an issue.
- `verified`: only after first review, second review, menu-instruction verification, and package validation.
- `archived`: no longer active but retained for traceability.

Never auto-verify. CSV imports and audit-session creation must always create draft or unverified work.

## Invalid Entries

Reject empty labels, placeholder tokens, template notices, missing evidence, missing platform, missing game version, missing creation path, duplicate stable IDs, fixture flags, and records without the standard screenshot set.
