# Phase 0 Evidence Intake

This directory is the supported local landing zone for new Wyatt-supplied College Football 27 evidence.

- Put new recordings and screenshots in `pending/`.
- Do not rename, trim, crop, recompress, or otherwise edit original files before intake.
- Intake output manifests are written in this directory.
- Intake records are research evidence only and never production catalog data.

Run:

```sh
npm run phase-zero:intake -- --path data/phase-zero/intake/pending
```
