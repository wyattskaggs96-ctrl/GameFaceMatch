# CF27 Matching Study Reviewer Checklist

**Status:** reviewer workflow only
**Study status:** NOT STARTED

Reviewer rules:

- Use only the verified production CF27 catalog release selected by the operator.
- Do not invent menu values, catalog IDs, or labels.
- Do not infer identity or sensitive traits.
- Do not use fixture records as real choices.
- Work independently before comparing with the second reviewer.

For each participant:

1. Confirm all required views are present and usable.
2. Record objective facial feature notes using controlled terms.
3. Select top-three verified head records in rank order.
4. Select verified hair and facial-hair records only when available.
5. Record a reason for each selection.
6. Record mismatch reasons where the recommendation is weak.
7. Compare reviewer A and reviewer B only after both independent forms are complete.
8. Log disagreement instead of averaging or guessing.

Reviewer output belongs in `data/phase-zero/manual_matching_reviews.template.csv`.
