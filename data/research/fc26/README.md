# FC26 Research Data

This directory contains EA SPORTS FC 26 player-creator research observations.

- `player_creator_research.json` is machine-readable research data from local source videos.
- `generated/` is ignored and may contain temporary contact sheets or extracted frames.
- `source-video-references/` is for local-only source media references; original videos must not be committed.

These records are not production catalog data and do not enable user-facing recommendations.
