# Phase 0 Data Dictionary

**Status:** canonical data dictionary  
**Last reviewed:** 2026-07-14  
**Scope:** current Phase 0 research artifacts under `data/phase-zero/` and preserved provenance artifacts under `data/research/cf27/`  
**Production status:** NOT PRODUCTION DATA

This dictionary defines how current Phase 0 artifacts should be interpreted. It does not create production catalog records and does not mark any observation verified.

## Artifact Classes

| Term | Meaning | Current canonical location | Notes |
| --- | --- | --- | --- |
| Source master | Original source video or capture file supplied by the owner. | Referenced from `data/phase-zero/video_inventory.*`; masters are not committed. | Preserve unchanged. Do not trim, rename destructively, recompress, or overwrite. |
| Derivative evidence | Extracted frame, contact sheet, crop, clip, renamed copy, or measurement derivative made from a source master. | Indexed in `data/phase-zero/evidence_manifest.*`; generated files may live under `data/phase-zero/derivative-frames/` or ignored generated directories. | Must preserve provenance to source video and timestamp. |
| Research candidate | Directly observed but unverified game record or menu fact. | `data/phase-zero/*.research.json` and `.csv`. | Not production data. Not recommendation eligible. |
| Verification candidate | Package prepared for a real second verifier. | `data/phase-zero/verification_assignment.json` and `verification_results.template.csv`. | A package/template is not verification. |
| Production record | A verified, catalog-manager-approved record in the production catalog. | `data/catalog/production/`. | Current count is zero. |
| Test fixture | Synthetic or generated data for automated tests. | `data/fixtures/test-only/`. | Must never load into production. |
| Historical export | Preserved older research package or report snapshot. | `data/research/cf27/exports/` and `data/research/cf27/reports/`. | Useful for provenance; not current status authority if contradicted by `data/phase-zero`. |

## Common Lifecycle Fields

| Field | Meaning | Allowed/current values | Required handling |
| --- | --- | --- | --- |
| `schemaVersion` | Version of the artifact schema. | Artifact-specific string. | Increment only with schema change and update tests/docs. |
| `generatedAt` / `updatedAt` | Timestamp for generation or update. | ISO-like timestamp string. | Preserve when generated by tooling; do not fake evidence timestamps. |
| `dataClass` | Data lifecycle class. | `RESEARCH_CANDIDATE`, `PHASE_ZERO_CAPTURE_REQUESTS`, `PRIMARY_RESEARCH_CANDIDATE`, template-specific values. | Must clearly distinguish research from production. |
| `sourceType` | Origin class for a record. | `shippingGameVideoResearch`, `researchDraft`, `testFixture`, `production`, etc. | Production validation rejects fixture/draft/unverified sources. |
| `productionStatus` | Production eligibility state. | `NOT_PRODUCTION_DATA`, production-specific approved states. | Current research artifacts must remain `NOT_PRODUCTION_DATA`. |
| `verificationStatus` | Verification lifecycle state. | `OBSERVED_PENDING_VERIFICATION`, `REQUESTED_NOT_CAPTURED`, `PRIMARY_RESEARCH_ONLY_NOT_SECOND_VERIFIED`, `NOT_VERIFIED`, etc. | Do not assign `VERIFIED` or `VERIFIED_WITH_NOTES` without a real second-verifier workflow. |
| `productionRecommendationsEnabled` | Whether data can drive public recommendations. | `false` for current Phase 0 research artifacts. | Must remain false until production publish gate passes. |

## Video Inventory Fields

| Field | Meaning | Notes |
| --- | --- | --- |
| `videoID` / `video_id` | Stable internal source-video identifier. | Use for evidence linkage instead of local absolute paths. |
| `originalFilename` | Owner-supplied source filename. | Preserve exactly. |
| `canonicalFilename` | Repository working name for the source. | Do not rename masters destructively. |
| `sha256` | Hash of the source file. | Used for duplicate detection and integrity. |
| `duration`, `dimensions`, `frameRate`, `codec` | Technical media metadata. | Detected with ffprobe/ffmpeg where available. |
| `opensSuccessfully` | Whether tooling can read the media. | Failed media stays preserved but cannot be accepted without repair/replacement. |
| `suitability` fields | Evidence strength for menu/count/order/visual/production use. | A video can be good menu evidence and poor production-comparison imagery. |

## Video Timeline Fields

| Field | Meaning | Notes |
| --- | --- | --- |
| `start_timestamp` / `startTimestamp` | Event start in source video. | Required for observed events. |

| `event_type` / `eventType` | Event category. | Examples: menu transition, selected option, stable frame, obstruction. |

| `usable_for_count` / `usable_for_order` / `usable_for_visual_analysis` | Evidence suitability flags. | Separate menu facts from visual matching suitability. |
| `extracted_frame_path` | Derivative evidence frame path. | Must remain relative and provenance-linked. |

## Current Known Data Gaps

- Exact Xbox platform/environment fields are unresolved; current IDs retain `XBOXUNKNOWN`.
- No production catalog item exists.
- No second-verifier result exists.
- No manual matching participant result exists.
- Hair, facial hair, mouth, jaw/chin/cheeks, eyebrows, body/height/weight/physique, and most dependency-test variables are not executed or cataloged.
- Older historical exports can have different counts from the current normalized `data/phase-zero` artifacts.

## Forbidden Interpretations

- Do not treat `OBSERVED_PENDING_VERIFICATION` as verified.
- Do not treat a research candidate as a production recommendation option.
- Do not treat fixture IDs as real College Football 27 records.
- Do not infer missing values between observed values.
- Do not infer selector completion without first/final/wrap or equivalent boundary evidence.
- Do not infer sensitive traits from subject or game-character imagery.
