## Reusable Runtime Head

Created a synthetic reusable neutral GLB:

`web/public/models/gameface/avatar/gameface_neutral_head_v1.glb`

Generated by:

`web/scripts/generate-gameface-neutral-head.mjs`

The neutral GLB contains a morphable head mesh plus synthetic neck, shoulders, jersey, hair, eyes, facial-hair shadow, and portrait background meshes. It contains no raw photographs, official game assets, FaceBuilder cameras, or private source-media paths.

## Morph System

Spec:

`docs/status/MORPH_TARGET_SPEC_V1.md`

Implemented morph target count: 28

All runtime morph weights are clamped to `[-1, 1]`. Low-confidence measurements are weighted conservatively. Unsupported measurements remain neutral.

## Scan-To-Morph Mapping

Implemented in:

`web/lib/avatar/gameface-3d-model.ts`

Current inputs come from the existing scan-derived `AvatarFeatureModel`, which is produced locally from the selected completed scan image. This keeps raw image use local and temporary; the 3D renderer receives only derived colors, normalized proportions, morph weights, and appearance configuration.

## Web Runtime

Implemented in:

`web/features/avatar/GameFace3DAvatarPreview.tsx`

The renderer lazy-loads Three.js and `GLTFLoader` only when a post-scan 3D avatar is requested. It renders a static portrait and does not run an unnecessary continuous animation loop.

Feature flag:

- `NEXT_PUBLIC_GAMEFACE_3D_AVATAR_V1=true`
- `GAMEFACE_3D_AVATAR_V1=true`

Default production behavior remains off unless explicitly enabled.

## Fallback

If WebGL, GLB loading, material setup, morph application, or rendering fails, the app falls back to the existing synthetic avatar. The UI should never show a blank avatar card or raw selfie.

## Remaining Non-Codex Gates

- Wyatt physical iPhone scan-completion confirmation.
- Wyatt subjective avatar-likeness review.
- Three or more consenting real-participant validation sessions.
- Production deployment decision after validation.
