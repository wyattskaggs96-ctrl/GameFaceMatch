# Manual Matching Repeatability Worksheet

**Status:** worksheet instructions only

Use `data/phase-zero/manual_matching_repeatability.template.csv`.

## Purpose

Repeatability records show whether a second capture of the same consenting participant produces a stable top-three recommendation set. This is not an identity test and does not prove biometric accuracy.

## Required Fields

- participant pseudonymous ID
- repeat scan ID
- repeat scan timestamp
- capture mode
- capture quality state
- original top-three catalog IDs
- repeat top-three catalog IDs
- whether top choice matched
- top-three overlap count from 0 to 3
- notes

The dashboard must show repeatability as `not measured` until enough real completed participant results exist.
