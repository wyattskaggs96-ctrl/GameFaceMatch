# Phase 0 Derivative Timeline Frames

This directory is for locally generated, full-resolution derivative frames from College Football 27 source videos.

- Master videos must not be stored here.
- Frames generated here are derivatives and must preserve source-video filename, timestamp, checksum, and provenance in `data/phase-zero/evidence_manifest.json`.
- Generated image files are ignored by Git by default.
- These frames are research evidence only and are not production catalog data.
