# Refund And Support Checklist

Complete this before any paid launch.

## Terms of purchase

- [ ] Define what a purchase unlocks.
- [ ] Confirm College Football 27 one-game pack name, price, currency, and one-time purchase wording.
- [ ] State that GameFace Match recommends closest available in-game settings and does not import faces into the game.
- [ ] State that College Football 27 catalog coverage depends on verified records.
- [ ] State that the one-game purchase is separate from any future multi-game suite.
- [ ] Include independent-app and trademark disclaimers.
- [ ] Explain browser RGB limitations and future native capture differences.

## Refund policy

- [ ] Define refund window.
- [ ] Define refund eligibility for catalog-unavailable errors.
- [ ] Define refund eligibility for user capture issues.
- [ ] Define no-refund cases if the product was delivered as described.
- [ ] Define how refunds affect entitlements and saved builds.

## Privacy policy

- [ ] Explain local-only raw image handling.
- [ ] Explain whether any payment provider receives customer contact or payment metadata.
- [ ] State that face data is not sold.
- [ ] State that face data is not used for biometric advertising.
- [ ] State that payment providers must not receive raw face media, landmarks, precise facial measurements, or unencrypted profile content.
- [ ] State that identity recognition is not implemented.
- [ ] Explain deletion controls.

## Support

- [ ] Choose support email.
- [ ] Set response-time expectation.
- [ ] Create refund request intake template.
- [ ] Create catalog error report intake template.
- [ ] Create deletion-help template.
- [x] Create support and incident workflow templates in `docs/support/CUSTOMER_SUPPORT_AND_INCIDENT_PLAYBOOK.md`.
- [x] Create machine-readable escalation rules in `data/support/customer_support_workflows.json`.
- [ ] Approve human escalation contacts for privacy, security, payment, catalog, accessibility, trademark, and child-safety issues.

## Sales tax

- [ ] Decide launch countries.
- [ ] Decide whether provider tax tooling is required.
- [ ] Confirm digital-goods tax obligations with an advisor.

## Minor purchases

- [ ] Decide whether age gate is required.
- [ ] Define parent or guardian consent approach if minors are allowed.
- [ ] Confirm payment-provider and legal requirements.

## Subscriptions, if later selected

- [ ] Show renewal price and period.
- [ ] Explain cancellation.
- [ ] Explain trial terms.
- [ ] Explain how access changes after cancellation.
- [ ] Provide required disclosures before checkout.

## Cancellation and chargebacks

- [ ] Define entitlement revocation behavior.
- [ ] Define support escalation path.
- [ ] Define evidence retained for disputes without storing raw face media.

## Digital-product delivery

- [ ] Define when a purchase is considered delivered.
- [ ] Define what happens when the catalog is unavailable.
- [ ] Define recovery when checkout succeeds but entitlement update fails.
- [ ] Define purchase restoration for the selected payment provider before paid launch.

## Marketing claims

- [ ] Avoid guaranteed resemblance.
- [ ] Avoid direct-import claims.
- [ ] Avoid official affiliation claims.
- [ ] Avoid fake discounts, fake urgency, fake testimonials, fake purchases, or fake revenue claims.
- [ ] Do not show fake result previews before purchase.
- [ ] Review all examples against the verified production catalog.
