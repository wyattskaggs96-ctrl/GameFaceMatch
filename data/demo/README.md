# Demo Data

Reserved namespace for non-production demo data.

- `sourceType` must be `demoData`.
- Demo data must never be imported into `data/catalog/production/`.
- Do not add real College Football 27 options here.
- `owner-review-demo-catalog.json` is synthetic `OWNER_REVIEW_DEMO` test data for Wyatt-only product evaluation. It is not human verification, not production catalog data, and not real matching-study evidence.
