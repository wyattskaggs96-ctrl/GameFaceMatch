# Phase 0 Annotation Forms

**NOT PRODUCTION DATA**

This directory contains blank forms and templates for future College Football 27 Phase 0 annotation work. Templates may contain placeholder tokens such as `REPLACE_WITH_VERIFIED_HEAD_STABLE_ID`; those tokens must never appear in production catalog packages.

The verified-head geometry annotation template is only for head presets that have already passed direct evidence review, second-person verification, and catalog-manager approval.
