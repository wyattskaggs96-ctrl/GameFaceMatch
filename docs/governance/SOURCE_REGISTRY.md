# Source Governance Registry

Last reviewed: 2026-07-12

This registry tells contributors which source documents control GameFace Match work. It exists to keep College Football 27 catalog, matching, capture, privacy, and verification behavior grounded in project-approved sources.

## Precedence Rules

1. Permanent rules in `AGENTS.md` and this source registry govern day-to-day engineering behavior.
2. `docs/GAMEFACE_MATCH_SOURCE_OF_TRUTH.md` is the binding product and technical source when implementation details conflict with ordinary docs.
3. Later accepted decisions in `docs/DECISIONS.md` supersede earlier implementation-order assumptions, especially the web-first MVP pivot.
4. Catalog, matching, privacy, mobile QA, deployment, monetization, and beta-readiness documents are binding for their specific domains when they do not contradict higher-precedence sources.
5. Test fixtures, templates, demo records, audit examples, and placeholder content are never production facts.
6. Unrelated Skaggs Systems materials are excluded and must not influence GameFace Match requirements.

## Contributor Checklist

Before changing catalog, matching, capture, privacy, or verification behavior:

1. Read `AGENTS.md`.
2. Read this registry.
3. Read `docs/GAMEFACE_MATCH_SOURCE_OF_TRUTH.md`.
4. Read the domain-specific binding docs listed above.
5. Confirm no unrelated Skaggs Systems source is being used as a requirement.
6. If sources conflict, follow the precedence rules and document the decision in `docs/DECISIONS.md` or a status audit.
